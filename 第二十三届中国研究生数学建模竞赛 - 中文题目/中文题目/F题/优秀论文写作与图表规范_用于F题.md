## 写作逻辑

1. **摘要先交付答案。** 用一小段交代问题、数据和总体方案，随后按题目小问写“核心方法—关键结果—结果含义”。能量化的结果写明指标、单位和适用的数据范围。样本中较强的摘要通常直接报出方案与数值，而不止写“效果较好”。
2. **正文按问题推进，每节形成完整闭环。** 推荐顺序为：问题目标与已有结果 → 数据与变量 → 假设及约束 → 模型/算法 → 求解设置 → 结果 → 对结果的解释。后续问题若沿用前一问模型，应先说清新增的目标、变量或约束，再写修改部分。
3. **模型叙述先讲选择理由，再给公式。** 每个关键公式说明变量、单位、目标及约束含义；算法流程解释输入、输出和停止条件。避免用大段通用算法介绍代替本题的具体设计。
4. **结果段落以可核查的证据收束。** 先给主结果表或主图，再回答“相比什么方案改进了多少、代价是什么、在什么条件下成立”。对异常或不符合预期的结果给出解释；最后明确本问所得结论如何成为下一问的输入。
5. **模型评价聚焦已观察到的能力与局限。** 评价应对应正文的实验、误差或约束；没有实验支撑的“泛化性强”“精度高”等表述不要单独作为结论。

## 图片排版

- **一张图回答一个问题。** 总体路线图负责显示各小问和数据之间的关系；模型结构图负责解释模块与信息流；结果图负责呈现趋势、分布或权衡。不要把全部公式和结论塞进一张路线图。
- **图前引出、图后解释。** 正文先说明图要回答的问题；图下放简短、独立可读的图题；图后指出读者应看到的关键变化及其数值或含义。样本中有“图后直接进入下一节”的情况，写本届论文时应补足解释。
- **可读性优先于装饰。** 采用一致的字号、线宽、颜色含义和小图顺序；多子图共用坐标范围时保持一致；图例、坐标轴、单位和样本范围完整。避免过密散点、过细流程框文字、低分辨率截图和大面积空白。
- **颜色承担编码。** 同一方案在全篇尽量使用同一颜色；必要时用线型或标记区分，确保灰度打印仍能识别。参考样本中的路线图可适度用色，结果图保持克制。

## 表格使用

- **表格用于精确比较，图用于看趋势。** 多个模型、资源方案或情景的精确指标优先放表中；性能曲线、Pareto 前沿、预算变化和不确定性范围适合用图。只有一个关键数字时，直接写入正文即可。
- **表题置于表上，图题置于图下。** 样本中这一用法较常见；全篇采用同一编号体系，例如“表 4-2”“图 4-3”，并在正文中按编号引用。
- **对比表写全比较口径。** 列名明确指标、单位、方向（↑/↓）、数据集或场景；方案行包含基线和本文方案；数值小数位按测量精度统一。显著性、区间或误差若有可靠计算，再在表注说明。
- **突出结论但不让样式喧宾夺主。** 近年样本里有简洁的横线表与浅色隔行背景。最佳值可适度加粗；不宜同时用大量色块、粗边框和多种字体。宽表应拆分或移至附录，正文保留能支撑论点的列。

## 应用于当前“算力约束下提升大语言模型能力的资源配置建模”

建议把论文主线写成：**资源和能力的定义 → 数据拟合与约束识别 → 资源配置模型 → 求解与方案比较 → 敏感性及应用建议**。若四问之间存在递进关系，摘要与总体路线图都应体现“前一问的估计结果如何进入下一问的决策”。

优先准备以下证据载体，是否纳入正文以实际结果为准：

| 载体 | 应回答的问题 | 需要交代的口径 |
|---|---|---|
| 数据与符号表 | 资源、能力、成本和效率如何定义？ | 来源、单位、时间/模型范围、缺失与处理方式 |
| 拟合/预测诊断图 | 能力与算力或数据规模的关系是否由数据支持？ | 样本点、拟合线、残差或误差、适用范围 |
| 方案对比表 | 在同一预算下，哪些配置更优？ | 预算、能力指标、成本、约束满足情况、基线 |
| 预算—效果曲线或 Pareto 图 | 增加资源的边际收益和权衡在哪里？ | 横纵轴定义、方案标记、不可行区域 |
| 敏感性图表 | 关键假设变化后结论是否稳定？ | 扰动参数、变化范围、主方案变化 |

最终写作时，以本题真实数据和已完成计算为准；表格不填推测数值，图片不通过重复绘制同一结果来增加篇幅。
